1. Conceitos Básicos de Teoria de Conjuntos

🎯 O que é um Conjunto?

Um conjunto é uma coleção bem definida de objetos distintos, chamados elementos. Representamos conjuntos com letras maiúsculas e elementos entre chaves.

A = {1, 2, 3, 4, 5}     B = {, 🍊, 🍋}

Características importantes:

  • Ordem não importa: {1,2} = {2,1}
  • Elementos não se repetem: {1,1,2} = {1,2}
  • Pertinência: x ∈ A (x pertence a A)

📝 Exemplo Prático

Seja o conjunto das cores primárias:

C = {x | x é cor primária} = { vermelho, 🔵 azul, amarelo}

Conjunto vazio: ∅ = {} (não tem elementos)

Conjunto unitário: U = {🌟} (apenas um elemento)

Animação: Elementos de Conjuntos

🏋️ Exercício 1

Dados os conjuntos A = {1, 2, 3} e B = {2, 3, 4}, responda:

  1. Qual é A ∩ B (intersecção)?
  2. {2, 3} ⊆ A? (é subconjunto?)
Resposta: 1) {2, 3}    2) Sim, pois todos os elementos de {2,3} estão em A.

🎨 3. Álgebra de Conjuntos

📊 Operações Fundamentais

União (∪): A ∪ B = {x | x ∈ A ou x ∈ B}

Intersecção (): A ∩ B = {x | x ∈ A e x ∈ B}

Diferença (-): A - B = {x | x ∈ A e x ∉ B}

Complemento: Ac = {x | x ∉ A}
Diagrama de Venn Interativo

🔢 Produto Cartesiano

O produto cartesiano A × B é o conjunto de todos os pares ordenados (a,b) onde a ∈ A e b ∈ B.

A = {🟥, 🟦}    B = {⭐, }

A × B = {(🟥,⭐), (🟥,🌙), (,⭐), (🟦,)}

Cardinalidade: |A × B| = |A| × |B| = 2 × 2 = 4 elementos

🔗 4. Relação entre Lógica e Conjuntos

Existe uma correspondência direta entre operações lógicas e operações com conjuntos:

🔴 OU (∨)

Corresponde à União (∪)

x ∈ A ∪ B ⇔ x ∈ A ∨ x ∈ B

🟢 E (∧)

Corresponde à Intersecção (∩)

x ∈ A ∩ B ⇔ x ∈ A ∧ x ∈ B

⚫ NÃO (¬)

Corresponde ao Complemento

x ∈ Ac ⇔ ¬(x ∈ A)

Implicação Lógica ↔ Subconjunto:
P → Q     equivale a     P ⊆ Q

🖥️ 5. Implementação Prática

💡 Algoritmo de União em Python

def uniao_conjuntos(A, B):
    """Retorna a união de dois conjuntos"""
    resultado = set(A)  # Copia A
    for elemento in B:
        resultado.add(elemento)
    return resultado

# Exemplo de uso
conjunto_a = {1, 2, 3}
conjunto_b = {3, 4, 5}
print(uniao_conjuntos(conjunto_a, conjunto_b))
# Saída: {1, 2, 3, 4, 5}

📜 6. Elementos da Teoria da Dedução

🧠 Componentes da Demonstração

  • Conjectura: Afirmação que se acredita ser verdadeira
  • Teorema: Conjectura demonstrada matematicamente
  • Lema: Teorema auxiliar usado na prova
  • Corolário: Consequência direta de um teorema

Exemplo de Teorema

Teorema: A soma dos primeiros n números ímpares é igual a n².

1 + 3 + 5 + ... + (2n-1) = n²

Demonstração por Indução:

  1. Base: Para n=1: 1 = 1² ✓
  2. Passo indutivo: Suponha válido para k, prove para k+1

️ 8. Relações: Grafos e Matrizes

Uma relação R de A em B é um subconjunto do produto cartesiano A × B.

Se A = {a, b} e B = {1, 2}
R = {(a,1), (a,2), (b,1)} é uma relação
Grafo de Relação Direcionada

📊 Matriz de Adjacência

Representação matricial de uma relação:

   1  2
a [1  1]
b [1  0]

1 = existe relação, 0 = não existe

10. Redes de Petri

Modelo matemático para sistemas concorrentes e distribuídos.

  • Transições (⬛): Representam eventos/ações

Grafo Não-Dirigido

🏋️ Exercício Final

Considere o grafo completo K₄ (4 vértices, todos conectados entre si).

Quantas arestas ele possui?

Resposta: Em um grafo completo com n vértices, o número de arestas é n(n-1)/2.
Para n=4: 4(3)/2 = 6 arestas.
