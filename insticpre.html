1. Conceito de Processo Estocástico 🎲

📌 Definição Fundamental

Um processo estocástico é uma coleção de variáveis aleatórias {X(t), t ∈ T} indexadas por um parâmetro t, geralmente interpretado como tempo.

Onde:

  • 📍 X(t): Estado do sistema no instante t
  • ⏰ T: Conjunto de índices (tempo discreto ou contínuo)
  • 🎯 E: Espaço de estados (valores possíveis de X(t))

📊 Visualização de um Processo Estocástico

💡 Exemplo Prático 1

Lançamento de Moedas: Seja Xₙ o resultado do n-ésimo lançamento (0=coroa, 1=cara). {Xₙ, n≥1} é um processo estocástico de tempo discreto.

🎲 Espaço de estados: E = {0, 1}

💡 Exemplo Prático 2

Processo de Chegadas: N(t) = número de clientes que chegaram até o instante t em uma fila. É um processo de tempo contínuo com valores inteiros não-negativos.

👥 Espaço de estados: E = {0, 1, 2, 3, ...}

📝 Exercício 1

Considere o preço de uma ação observado diariamente. Classifique este processo quanto a:

  1. Tempo (discreto ou contínuo)
  2. Espaço de estados (discreto ou contínuo)
Resposta: Tempo discreto (observações diárias) e espaço de estados contínuo (preço pode assumir qualquer valor real positivo). 📈

2. Caracterização e Exemplos de Processos Estocásticos 📐

📊 Funções de Distribuição

Um processo estocástico é completamente caracterizado pelas suas funções de distribuição finito-dimensionais:

F t 1 , … , t n ( x 1 , … , x n ) = P ( X ( t 1 ) ≤ x 1 , … , X ( t n ) ≤ x n )

📈 Momentos de um Processo

Função Média:

m X ( t ) = E [ X ( t ) ]

Função de Autocorrelação:

R X ( t 1 , t 2 ) = E [ X ( t 1 ) X ( t 2 ) ]

🎯 Exemplo: Processo de Wiener (Movimento Browniano)

🌊 Processo de Poisson

Um dos processos mais importantes! Caracterizado por:

  • 📍 N(0) = 0
  • 📍 Incrementos independentes
  • 📍 Incrementos estacionários
  • 📍 P(N(t+h) - N(t) = 1) = λh + o(h)
  • P(N(t+h) - N(t) ≥ 2) = o(h)
P [ N ( t ) = k ] = ( λ t ) k k ! e − λ t

Exercício 2

Em um processo de Poisson com taxa λ = 3 clientes/hora, calcule a probabilidade de chegarem exatamente 5 clientes em 2 horas.

Resolução:
λt = 3 × 2 = 6
P(N(2) = 5) = (6/5!) × e⁻⁶
P(N(2) = 5) = (7776/120) × 0.00248
P(N(2) = 5) ≈ 0.1606 ou 16.06%

3. Caracterização e Exemplos de Processos de Markov 🔄

🎯 Propriedade de Markov

Um processo estocástico {X(t), t ≥ 0} possui a propriedade de Markov se:

P [ X ( t ) ≤ x | X ( t 1 ) = x 1 , … , X ( t n ) = x n ] = P [ X ( t ) ≤ x | X ( t n ) = x n ]

"O futuro depende apenas do presente, não do passado"

🎲 Cadeia de Markov Discreta - Simulação

📊 Matriz de Transição

P = p11 p12 … p21 p22 … ⋮ ⋱

Onde pᵢⱼ = P(Xₙ₊₁ = j | Xₙ = i)

🌤️ Exemplo: Previsão do Tempo

Suponha que o tempo amanhã depende apenas do tempo de hoje:

  • ☀️ Se hoje está sol: 80% chance de sol amanhã, 20% chuva
  • 🌧️ Se hoje está chovendo: 60% chance de chuva, 40% sol
P = 0.8 0.2 0.4 0.6

📝 Exercício 3

Dada a matriz de transição acima e sabendo que hoje está sol (estado 1), qual a probabilidade de estar chovendo daqui a 2 dias?

Resolução:
Precisamos calcular P²:
P² = P × P
p₁₂(2) = 0.8×0.2 + 0.2×0.6 = 0.16 + 0.12 = 0.28
Resposta: 28% de chance de chuva em 2 dias ️

4. Cadeias de Markov de Tempo Contínuo ⏱️

🔄 Definição

Uma cadeia de Markov de tempo contínuo é um processo estocástico {X(t), t ≥ 0} com espaço de estados discreto que satisfaz a propriedade de Markov e é homogêneo no tempo.

Matriz de Taxas de Transição Q:

q i j = lim h → 0 p i j ( h ) h , i ≠ j

📊 Diagrama de Transição de Estados

Equações de Kolmogorov

Equações Diretas (Forward):

P ′ ( t ) = P ( t ) Q

Equações Reversas (Backward):

P ′ ( t ) = Q P ( t )

🏥 Exemplo: Sistema de Dois Servidores

Considere um sistema com dois servidores onde:

  • Taxa de chegada: λ = 2 clientes/hora
  • Taxa de serviço: μ = 3 clientes/hora por servidor
  • 👥 Estados: 0, 1, 2 clientes no sistema
Q = −2 2 0 3 −5 2 0 6 −6

📝 Exercício 4

Para o sistema acima, encontre as probabilidades de estado estacionário π₀, π₁, π₂ resolvendo πQ = 0 com Σπᵢ = 1.

Resolução:
πQ = 0 gera:
-2π₀ + 3π₁ = 0 → π₁ = (2/3)π₀
2π₀ - 5π₁ + 6π₂ = 0
2π₁ - 6π₂ = 0 → π₂ = (1/3)π₁ = (2/9)π₀
π₀ + π₁ + π₂ = 1
π₀(1 + 2/3 + 2/9) = 1
π₀ = 9/17 ≈ 0.529
π₁ = 6/17 ≈ 0.353
π₂ = 2/17 ≈ 0.118
Resposta: π = [0.529, 0.353, 0.118] ✅

5. Filas Markovianas em Equilíbrio ⚖️

🎯 Condição de Equilíbrio

Um sistema de filas está em equilíbrio (estado estacionário) quando as probabilidades de estado não mudam com o tempo:

lim t → ∞ P [ X ( t ) = j ] = π j

📊 Evolução para o Equilíbrio

📐 Equações de Equilíbrio

π Q = 0 , ∑ i = 0 ∞ π i = 1

🏪 Exemplo: Loja com Caixa Único

Em uma loja, clientes chegam segundo um processo de Poisson com taxa λ = 10/hora e são atendidos com tempo exponencial de média 5 minutos (μ = 12/hora).

Fator de utilização: = λ/μ = 10/12 = 5/6 ≈ 0.833

Distribuição Geométrica:

π n = ( 1 − ρ ) ρ n , n ≥ 0

Exercício 5

Para o sistema acima, calcule:

  1. Probabilidade de não haver clientes na loja
  2. Probabilidade de haver pelo menos 3 clientes
Resolução:
1. π₀ = 1 - ρ = 1 - 5/6 = 1/6 ≈ 0.167 (16.7%)
2. P(N ≥ 3) = 1 - P(N < 3) = 1 - (π₀ + π₁ + π₂)
π₁ = (1/6)(5/6) = 5/36
π₂ = (1/6)(5/6)² = 25/216
P(N ≥ 3) = 1 - (36/216 + 30/216 + 25/216) = 1 - 91/216
P(N ≥ 3) = 125/216 ≈ 0.579 (57.9%) 📊

6. Processos de Renovação 🔄

📌 Definição

Um processo de renovação é um processo de contagem {N(t), t ≥ 0} onde os tempos entre eventos consecutivos são variáveis aleatórias independentes e identicamente distribuídas (i.i.d.).

N ( t ) = max { n : S n ≤ t }

Onde Sₙ = X₁ + X₂ + ... + Xₙ é o tempo do n-ésimo evento

📊 Processo de Renovação - Simulação

📐 Teorema da Renovação

lim t → ∞ N ( t ) t = 1 E [ X ] = 1 μ

💡 Exemplo: Substituição de Lâmpadas

Uma lâmpada dura em média 1000 horas (distribuição exponencial). Qual a taxa de substituição a longo prazo?

Resposta: 1/1000 = 0.001 lâmpadas/hora ou 1 lâmpada a cada 1000 horas 💡

Função de Renovação:

M ( t ) = E [ N ( t ) ] = ∑ n = 1 ∞ F n ( t )

📝 Exercício 6

Se o tempo entre falhas de uma máquina segue uma distribuição uniforme entre 8 e 12 horas, qual o número esperado de falhas em 100 horas?

Resolução:
E[X] = (8 + 12)/2 = 10 horas
Pelo teorema da renovação:
M(100) ≈ 100/E[X] = 100/10 = 10 falhas
Resposta: Aproximadamente 10 falhas em 100 horas 🔧

8. As Filas M/G/1, M/M/1, M/M/s e M/M/∞ 🎰

🎯 Fila M/M/1

O modelo mais básico e importante! Características:

  • Chegadas: Processo de Poisson (taxa λ)
  • Serviço: Exponencial (taxa μ)
  • 1 servidor
  • Fila ilimitada
  • Disciplina: FIFO

Fórmulas Fundamentais M/M/1:

ρ = λ μ < 1 L = ρ 1 − ρ , W = 1 μ − λ L q = ρ 2 1 − ρ , W q = ρ μ − λ

📊 Comportamento M/M/1 vs ρ

🔄 Fórmula de Pollaczek-Khinchine (M/G/1)

L q = λ 2 σ 2 + ρ 2 2 ( 1 − ρ )

Onde σ² é a variância do tempo de serviço

👥 Sistema M/M/s (Múltiplos Servidores)

P ( 0 ) = ∑ n = 0 s − 1 ( λ / μ ) n n ! + ( λ / μ ) s s ! 1 1 − ρ − 1

🏥 Exemplo Prático M/M/1

Em um posto de saúde, pacientes chegam a uma taxa de 4/hora (λ=4) e são atendidos em média em 10 minutos (μ=6/hora).

Cálculos:

  • ρ = 4/6 = 2/3 ≈ 0.667
  • L = (2/3)/(1-2/3) = 2 pacientes
  • W = 1/(6-4) = 0.5 horas = 30 minutos
  • Lq = (4/9)/(1/3) = 4/3 ≈ 1.33 pacientes na fila
  • Wq = (2/3)/(6-4) = 1/3 hora = 20 minutos

📝 Exercício 8

Em um sistema M/M/2 com λ=10/hora e μ=8/hora por servidor, calcule ρ e verifique se o sistema é estável.

Resolução:
ρ = λ/(s×μ) = 10/(2×8) = 10/16 = 0.625
Como ρ < 1, o sistema é estável ✅
O sistema opera a 62.5% da capacidade total.

9. Redes de Filas - Abertas e Fechadas 🌐

🔗 Definição de Rede de Filas

Uma rede de filas é um conjunto de nós (serviços) interconectados onde clientes podem se mover entre os nós seguindo regras de roteamento.

📊 Rede de Filas Aberta - Jackson Network

Teorema de Jackson (Redes Abertas)

Para uma rede com J nós, as equações de tráfego são:

λ j = γ j + ∑ i = 1 J λ i p i j

Onde γⱼ = taxa externa de chegada no nó j

🏭 Exemplo: Sistema de Produção

Considere uma fábrica com 3 estações:

  • 📥 Estação 1: Montagem inicial (λ₁ = 10/hora)
  • 🔧 Estação 2: Acabamento (70% vão para cá)
  • ✅ Estação 3: Inspeção final (30% vão direto)
  • 🔄 20% da inspeção retornam para acabamento

🔄 Redes de Filas Fechadas (Gordon-Newell)

Em redes fechadas com N clientes circulando:

P ( n 1 , … , n J ) = 1 G ( N ) ∏ j = 1 J ρ n j

📝 Exercício 9

Em uma rede com 2 nós, chegadas externas λ₁=5, λ₂=3. Probabilidades de roteamento: p₁₂=0.4, p₂₁=0.3. Calcule as taxas totais λ₁ e λ₂.

Resolução:
λ₁ = 5 + 0.3λ₂
λ₂ = 3 + 0.4λ₁
Substituindo:
λ₁ = 5 + 0.3(3 + 0.4λ₁)
λ₁ = 5 + 0.9 + 0.12λ₁
0.88λ₁ = 5.9
λ₁ ≈ 6.70
λ₂ = 3 + 0.4(6.70) ≈ 5.68
Resposta: λ₁ ≈ 6.70, λ₂ ≈ 5.68 🔄

10. Introdução à Análise Operacional 📊

🎯 Lei de Little

A relação fundamental da teoria de filas:

L = λ W

"O número médio no sistema = taxa de chegada × tempo médio no sistema"

📈 Visualização da Lei de Little

🔍 Análise de Filas Isoladas

📋 Métricas de Desempenho

  • Throughput (X): Taxa de saída do sistema
  • Utilização (U): Fração de tempo ocupado
  • Tempo de Resposta (R): Tempo total no sistema
  • Demanda (D): Tempo total de serviço necessário

Lei da Utilização:

U = X D = λ / μ

Lei do Tempo de Resposta:

R = S 1 − U

Onde S é o tempo de serviço

Análise de Redes de Filas

🖥️ Exemplo: Sistema Cliente-Servidor

Um sistema com:

  • 100 usuários (think time Z = 10s)
  • 💻 Servidor com D = 0.5s por transação
  • Throughput máximo: X₀ = N/(D+Z) = 100/10.5 ≈ 9.52 trans/s
  • ️ Tempo de resposta mínimo: R₀ = D = 0.5s

📝 Exercício 10

Em um sistema observado por 1 hora, foram processadas 3600 transações. O tempo médio de resposta foi 2 segundos. Qual o número médio de transações no sistema?

Resolução:
λ = 3600 trans/hora = 1 trans/segundo
W = 2 segundos
Pela Lei de Little:
L = λ × W = 1 × 2 = 2 transações
Resposta: 2 transações em média no sistema 📊

11. Conceito de Planeamento de Capacidade 📈

Definição

Planeamento de capacidade é o processo de determinar os recursos necessários (servidores, largura de banda, etc.) para atender à demanda atual e futura mantendo níveis aceitáveis de desempenho.

Curva de Crescimento de Demanda vs Capacidade

📐 Métricas de Planeamento

Fator de Carga:

ρ = λ s μ

Cenários de Planeamento

  • Cenário Base: Demanda atual conhecida
  • Cenário de Crescimento: Projeção de aumento (ex: 20%/ano)
  • Cenário de Pico: Demanda máxima esperada
  • Cenário de Contingência: Falhas e recuperação

📝 Exercício 11

Um data center processa 1000 requisições/hora com tempo médio de 2 segundos. Planeja-se um aumento de 50% na demanda. Quantos servidores adicionais são necessários se cada servidor processa 400 req/hora?

Resolução:
Demanda atual: 1000 req/hora
Demanda futura: 1000 × 1.5 = 1500 req/hora
Capacidade por servidor: 400 req/hora
Servidores necessários: 1500/400 = 3.75 → 4 servidores
Servidores atuais: 1000/400 = 2.5 → 3 servidores
Resposta: Adicionar 1 servidor (total de 4) ️

12. Aplicação em Redes de Computadores 🌐

💻 Teoria de Filas em Redes

A teoria de filas é essencial para analisar e projetar:

  • 🌐 Redes de computadores e internet
  • 📡 Sistemas de telecomunicações
  • 🔗 Protocolos de múltiplo acesso
  • 📱 Redes sem fio (WiFi, 5G)

📊 Modelo de Router com Múltiplas Filas

📡 Sistemas de Múltiplo Acesso

ALOHA e CSMA/CD

ALOHA Puro:

  • Throughput máximo: S = Ge^(-2G)
  • Máximo em G=0.5: S_max ≈ 0.184 (18.4%)

CSMA/CD (Ethernet):

  • Throughput muito superior
  • Evita colisões detectando portadora

Fórmula de Erlang-B (Perda):

B ( s , A ) = A s / s ! ∑ k = 0 s A k / k !

Onde A = λ/μ (tráfego em Erlangs)

🌐 Exemplo: Dimensionamento de Links

Um link de internet deve atender:

  • 📊 1000 usuários
  • 📤 Cada usuário gera 0.01 Erlangs
  • 🎯 Probabilidade de bloqueio: 1%

Solução: Usar fórmula de Erlang-B iterativamente para encontrar s tal que B(s, 10) ≤ 0.01

📱 Redes de Filas em Sistemas Distribuídos

Lei de Amdahl:

S = 1 ( 1 − p ) + p / N

Onde p = fração paralelizável, N = número de processadores

📝 Exercício 12

Em uma rede Ethernet com 100 estações, cada uma transmitindo 10 pacotes/segundo de 1000 bytes. O link tem capacidade de 100 Mbps. Qual a utilização do link?

Resolução:
Taxa total de dados: 100 × 10 × 1000 × 8 = 8,000,000 bps
Capacidade do link: 100 Mbps = 100,000,000 bps
Utilização: ρ = 8,000,000 / 100,000,000 = 0.08 = 8%
Resposta: 8% de utilização ✅
O link está subutilizado, podendo suportar mais tráfego.
