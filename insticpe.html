1. Fenómenos Determinísticos e Probabilísticos

🎯 Conceitos Fundamentais

Fenómenos Determinísticos: São aqueles que, conhecidas as condições iniciais, permitem prever com exatidão o resultado final.

Fenómenos Probabilísticos (Aleatórios): São aqueles que, mesmo conhecidas as condições iniciais, não permitem prever com certeza o resultado, apenas a probabilidade de ocorrência.

📐 Exemplos

Determinístico: Se um carro viaja a 60 km/h durante 2 horas, percorrerá exatamente 120 km.

Probabilístico: 🎲 Ao lançar um dado, não sabemos qual face cairá, mas sabemos que cada uma tem 1/6 de chance.

✏️ Exercícios

1. Classifique como determinístico (D) ou probabilístico (P):

  • a) Previsão do tempo para amanhã
  • b) Cálculo da área de um círculo de raio 5cm
  • c) Resultado de um sorteio da loteria
a) P - Depende de múltiplas variáveis atmosféricas
b) D - A = πr² = 25π cm² (exato)
c) P - Resultado aleatório

4. Esperança Matemática

🎲 Definição

A esperança matemática ou valor esperado de uma variável aleatória é a média ponderada de todos os valores possíveis, onde os pesos são as probabilidades de ocorrência.

📐 Fórmulas

E [ X ] = ∑ i = 1 n x i ⋅ P ( x i )

Variável Discreta

E [ X ] = ∫ − ∞ ∞ x ⋅ f ( x ) d x

Variável Contínua

✏️ Exercícios

4. Em um jogo, você ganha R$10 com probabilidade 0.3, R$5 com probabilidade 0.5 e perde R$2 com probabilidade 0.2. Qual o valor esperado?

E[X] = 10(0.3) + 5(0.5) + (-2)(0.2) = 3 + 2.5 - 0.4 = R$ 5,10

5. Momentos

📊 Definição

Momentos são medidas que descrevem a forma da distribuição de uma variável aleatória.

  • 1º momento: Média (tendência central)
  • 2º momento: Variância (dispersão)
  • 3º momento: Assimetria
  • 4º momento: Curtose (achatamento)

📐 Fórmulas

μ k = E [ ( X − μ ) k ]

k-ésimo momento central

σ 2 = E [ ( X − μ ) 2 ]

Variância (2º momento)

✏️ Exercícios

5. Calcule a variância de X onde X assume valores {1, 2, 3} com probabilidades {0.2, 0.5, 0.3}

μ = 1(0.2) + 2(0.5) + 3(0.3) = 2.1
σ² = (1-2.1)²(0.2) + (2-2.1)²(0.5) + (3-2.1)²(0.3) = 0.49

6. Funções Geratrizes de Momentos

Definição

A função geratriz de momentos (FGM) de uma variável aleatória X é definida como:

📐 Fórmula

M X ( t ) = E [ e t X ]

Propriedade importante: A k-ésima derivada de M_X(t) avaliada em t=0 fornece o k-ésimo momento:

μ k = M ( k ) ( 0 )

✏️ Exercícios

6. Encontre a FGM de uma variável Bernoulli com parâmetro p.

M_X(t) = E[e^(tX)] = e^(t·0)·(1-p) + e^(t·1)·p = (1-p) + pe^t

10. Os Axiomas da Probabilidade

📜 Axiomas de Kolmogorov

  1. Não-negatividade: P(A) ≥ 0 para todo evento A
  2. Normalização: P(Ω) = 1
  3. Aditividade: Se A₁, A₂, ... são mutuamente exclusivos, então P(∪A) = ΣP(Aᵢ)

📐 Propriedades Derivadas

P ( A c ) = 1 − P ( A )

Probabilidade do complementar

P ( A ∪ B ) = P ( A ) + P ( B ) − P ( A ∩ B )

Regra da adição

️ Exercícios

10. Se P(A) = 0.4 e P(B) = 0.5 e P(A∩B) = 0.2, calcule P(A∪B).

P(A∪B) = 0.4 + 0.5 - 0.2 = 0.7

📐 Fórmulas

P ( A | B ) = P ( A ∩ B ) P ( B )
P ( A | B ) = P ( B | A ) ⋅ P ( A ) P ( B )

Teorema de Bayes

✏️ Exercícios

11. Em uma população, 1% tem uma doença. Um teste tem 95% de acerto para doentes e 90% para saudáveis. Se o teste deu positivo, qual a probabilidade de realmente ter a doença?

P(Doente|+) = [P(+|Doente)×P(Doente)] / P(+) = (0.95×0.01) / [(0.95×0.01)+(0.10×0.99)] ≈ 0.0876 ou 8.76%

12. Variáveis Aleatórias

📊 Definição

Uma variável aleatória é uma função que associa um número real a cada resultado de um experimento aleatório.

  • Discreta: Assume valores contáveis (ex: número de filhos)
  • Contínua: Assume valores em intervalos (ex: altura, peso)

📐 Exemplos

Discreta: X = número de caras em 3 lançamentos de moeda → X ∈ {0, 1, 2, 3}

Contínua: Y = tempo de vida de uma lâmpada → Y ∈ [0, ∞)

️ Exercícios

a) Discreta (valores inteiros: 0, 1, 2, ...)
b) Contínua (qualquer valor real em um intervalo)

13. Função de Distribuição Acumulada

📈 Definição

A função de distribuição acumulada (FDA) de uma variável aleatória X é definida por:

📐 Fórmula

F ( x ) = P ( X ≤ x )

Propriedades:

  • 0 ≤ F(x) ≤ 1
  • F(x) é não-decrescente
  • lim_(x→-∞) F(x) = 0
  • lim_(x→∞) F(x) = 1

✏️ Exercícios

13. Se X tem distribuição uniforme em [0,1], qual é F(0.7)?

F(0.7) = P(X ≤ 0.7) = 0.7 (para distribuição uniforme)

14. Função Densidade de Probabilidade

📊 Definição

Para variáveis contínuas, a função densidade de probabilidade (fdp) f(x) satisfaz:

📐 Propriedades

f ( x ) ≥ 0 e ∫ − ∞ ∞ f ( x ) d x = 1
P ( a ≤ X ≤ b ) = ∫ a b f ( x ) d x

16. Teorema do Limite Central

🎯 Enunciado

Seja X₁, X₂, ..., Xₙ uma amostra aleatória de uma população com média μ e variância σ². Então, quando n é grande:

📐 Fórmula

Z = X ¯ − μ σ / n ∼ N ( 0 , 1 )

Importância: Permite usar a distribuição normal mesmo quando a população original não é normal, desde que n ≥ 30.

✏️ Exercícios

16. Uma população tem μ=50 e σ=10. Qual a probabilidade de que a média de uma amostra de n=100 seja maior que 52?

Z = (52-50)/(10/√100) = 2/1 = 2
P(Z > 2) = 1 - 0.9772 = 0.0228 ou 2.28%
