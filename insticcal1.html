1. Noções Básicas de Lógica e Indução Matemática 🔢

1.1 Proposições e Conectivos Lógicos

Proposição: É uma sentença declarativa que pode ser verdadeira (V) ou falsa (F), mas não ambas.

Exemplos:

  • "2 + 2 = 4" é uma proposição verdadeira ✅
  • "3 > 5" é uma proposição falsa ❌
  • "Que horas são?" não é proposição (é pergunta)

Conectivos Lógicos Fundamentais:

NomeSímboloLeituraExemplo
Negação¬ ou ~não p¬(x > 0) ≡ x ≤ 0
Conjunção∧p e qV ∧ F = F
Disjunção∨p ou qV ∨ F = V
Condicional→se p então qp → q
Bicondicional↔p sse qp ↔ q

1.2 Quantificadores

∀x∈ℝ,x2≥0
Para todo x real, x² é maior ou igual a zero
∃x∈ℝ|x2=4
Existe x real tal que x² = 4

1.3 Princípio da Indução Matemática 🎯

O princípio da indução é usado para provar proposições sobre números naturais.

Passos:

  1. Base: Mostrar que P(1) é verdadeira
  2. Hipótese de Indução: Supor que P(k) é verdadeira
  3. Tese: Provar que P(k+1) é verdadeira
📝 Exemplo 1.1: Soma dos n primeiros naturais

Provar que: 1+2+…+n=n(n+1)2

Demonstração:

  1. Base (n=1): 1 = 1(2)/2 = 1 ✓
  2. Hipótese: 1+2+…+k = k(k+1)/2
  3. Tese: 1+2+…+k+(k+1) = (k+1)(k+2)/2
k(k+1)2+(k+1)=(k+1)(k+2)2

2. Noções Básicas de Sucessões 📈

2.1 Definição de Sucessão

Uma sucessão (ou sequência) é uma função cujo domínio é o conjunto dos números naturais ℕ.

Notação: (aₙ) ou {aₙ} onde n ∈ ℕ

Exemplo: aₙ = 2n + 1 → 3, 5, 7, 9, 11, …

2.2 Tipos de Sucessões

TipoFórmulaExemplo
Aritméticaaₙ = a₁ + (n-1)r2, 5, 8, 11… (r=3)
Geométricaaₙ = a₁ · q^(n-1)3, 6, 12, 24… (q=2)
Recorrenteaₙ = f(aₙ₋₁)Fibonacci: aₙ = aₙ₋₁ + aₙ₋₂

2.3 Limite de uma Sucessão

limn→∞an=L

Para ε > 0 arbitrário, existe N tal que |aₙ - L| < ε para todo n > N.

📝 Exemplo 2.1: Sucessão convergente

aₙ = 1/n → Termos: 1, 1/2, 1/3, 1/4, …

limn→∞1n=0

📊 Visualização de Sucessões

🔵 aₙ = 1/n (converge para 0)   🔴 bₙ = n/(n+1) (converge para 1)

2.4 Sucessões Monótonas e Limitadas

Teorema: Toda sucessão monótona e limitada é convergente.

  • Crescente: aₙ₊₁ ≥ aₙ
  • Decrescente: aₙ₊₁ ≤ aₙ
  • Limitada: ∃M : |aₙ| ≤ M

3. Funções: Conceptualização e Propriedades 🎯

3.1 Definição Formal

Sejam A e B conjuntos não vazios. Uma função f: A → B associa a cada x ∈ A um único y ∈ B.

  • Domínio D(f): conjunto de entrada
  • Contradomínio CD(f): conjunto B
  • Imagem Im(f): {y ∈ B | y = f(x)}

3.2 Classificação

TipoDefiniçãoExemplo

f-1(f(x))=x

7. Derivadas: Definição e Interpretações 📐

7.1 Definição

f′(x)=limh→0f(x+h)-f(x)h

7.2 Interpretação Geométrica

f'(x₀) = coeficiente angular da reta tangente em (x₀, f(x₀)).

Reta tangente: y - y₀ = f'(x₀)(x - x₀)

7.3 Interpretação Física

  • 🚗 Velocidade: v(t) = s'(t)
  • 🏎️ Aceleração: a(t) = s''(t)
📝 Exemplo 7.1: f(x) = x²

f'(x) = lim[(x+h)² - x²]/h = lim[2xh + h²]/h = lim(2x+h) = 2x
